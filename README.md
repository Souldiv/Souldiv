## Amrut

`Kubernetes` · `Cilium` · `Terraform` · `OpenTofu` · `Ansible` · `Nix` · `Rust` · `Python`

DevOps and network engineer. I work on the layer between code and the machines it runs on.

Most of that is Kubernetes and the networking underneath it — the CNI, the routing, the policy, the things nobody thinks about until a packet goes missing. Around it sits the rest of the platform: cloud described in Terraform, hosts configured in Ansible, my own machines declared in Nix so that a rebuild is one command.

I write code too. Rust when a service should be small and hard to break, Python when it needs to exist by Thursday. But the part I like is the other side of the deployment — making the thing reproducible, legible, and dull in the way good infrastructure is dull.

Set something up twice by hand and you get two different things. Most of what I do is an argument against that.
